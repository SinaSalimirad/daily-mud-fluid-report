# Application Folder Structure

Monorepo managed with Bun workspaces (`apps/*`, `packages/*`).

## Root

```
daily-mud-fluid-report
├───.github
│   └───dependabot.yml
├───docs
├───apps
│   ├───api                 # Elysia backend
│   └───web                 # Next.js frontend
├───infra
│   ├───docker
│   └───nginx
├───.dockerignore
├───.env.example
├───.gitignore
├───.npmrc
├───biome.json
└───package.json            # workspaces + root scripts
```

## Backend Folder Structure

`apps/api` — feature-based modules; each module has a controller, a service and a model.

```
apps/api
├───drizzle
├───src
│   ├───index.ts                # app bootstrap, registers modules
│   ├───config
│   │   ├───db.config.ts        # db client (server-side only)
│   │   └───env.config.ts
│   ├───helper
│   ├───module
│   │   └───product
│   │       ├───index.ts        # controller (Elysia instance)
│   │       ├───service.ts      # business logic
│   │       └───model.ts        # validation + types (DTO)
│   ├───repository              # db queries
│   ├───validation
│   └───schema
├───package.json
├───tsconfig.json
└───drizzle.config.ts
```

| File         | Responsibility                                 |
| ------------ | ---------------------------------------------- |
| `index.ts`   | HTTP routes and request validation             |
| `service.ts` | Business logic and database queries            |
| `model.ts`   | Validation schemas and types derived from them |
